## ✨ What is ReelWide?

**ReelWide** is a simple and modern web application designed to transform Facebook Reels into landscape-format videos.

Paste a Reel URL, choose your preferred aspect ratio, and create a viewing experience that fits your screen.

> Built for creators, viewers, and anyone who loves a wider frame.

## 🚀 Features

| Feature | Description |
|---|---|
| 🔗 Facebook Reel URL | Paste your Reel link |
| 📺 Landscape Conversion | Convert vertical content into wider formats |
| 🎛️ Custom Aspect Ratio | Choose your preferred landscape ratio |
| 🎨 Clean UI | Simple and intuitive interface |
| ⚡ Fast Experience | Designed for a smooth workflow |

## 📦 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/reelwide.git
cd reelwide
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

Open the local URL shown in your terminal.
